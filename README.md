# 🎮 Block Game

A Tetris-inspired block puzzle game built using **Python and Pygame**.

This project was created to practice Python programming, Object-Oriented Programming (OOP), game loops, event handling, collision detection, scoring, and game-state management.

---

## ✨ Features

- 🎮 Keyboard-based controls
- ⬅️ Move blocks left
- ➡️ Move blocks right
- ⬇️ Move blocks down
- 🔄 Rotate blocks
- 🧮 Score tracking
- 🧱 Automatic block falling
- 🎯 Next block preview
- 💀 Game-over detection
- 🎚️ Three difficulty levels:
  - 🟢 Easy
  - 🟡 Medium
  - 🔴 Hard
- 🌐 Can be prepared for browser deployment using Pygbag

---

## 🕹️ Controls

| Key | Action |
|---|---|
| ⬅️ Left Arrow | Move block left |
| ➡️ Right Arrow | Move block right |
| ⬇️ Down Arrow | Move block down faster |
| ⬆️ Up Arrow | Rotate block |

---

## 🎚️ Difficulty Levels

The game includes three difficulty levels.

### 🟢 Easy

Blocks fall at a slower speed, making the game easier for beginners.

### 🟡 Medium

Blocks fall at a normal speed and provide a balanced gameplay experience.

### 🔴 Hard

Blocks fall faster, increasing the challenge.
